# 安全说明

最后更新：2026-07-29

## 凭据边界

- API Key 只写入 macOS Keychain，不应写入源码、`.env`、截图、日志、Issue、PR 或聊天记录。
- 设置页不会回显已保存的 Key；留空保存表示保留当前 Key。
- CLI 的 `set` 命令只从隐藏的标准输入接收 Key，不接受 Key 作为命令行参数。
- 诊断输出不包含请求 Header、请求文本、服务端原始响应体或 Keychain 内容。

## 使用者责任

- 使用你自己的豆包账户和 API Key，并为该账户设置适当的权限、预算和配额。
- 如果 Key 曾出现在终端、截图、聊天、提交历史或公开页面，请立即在服务商控制台撤销或轮换它。
- 不要把任何真实 Key 提交到派生仓库。

## 报告漏洞

仓库正式公开前，尚未配置安全漏洞的私密报告渠道。请不要在公开渠道披露可利用细节或凭据。维护者应在创建公开仓库时启用 GitHub Private Vulnerability Reporting，并在此处补充确认后的私密报告入口。

## 支持范围

当前版本是 macOS 源码构建的 Developer Preview，尚未完成 Developer ID 签名、公证或安装包分发。请在隔离的开发环境中构建和评估它。
