# 隐私说明

最后更新：2026-08-03

Omi 是一个本地运行的 macOS 文本朗读工具。它不会读取完整对话、监听屏幕或自动捕获新内容。

## 收集与处理的数据

- 只有在你主动复制文本并触发朗读后，Omi 才读取当前剪贴板中的文本；若剪贴板同时提供 HTML，Omi 只在本地用它识别列表或表格结构。
- Omi 在本地移除高置信度表格并拦截无有效文字内容，只把过滤后的可朗读纯文本发送到你自行配置的豆包 TTS 服务，用于生成语音；原始 HTML 不会发送。
- “文本预览”只在你聚焦文本框并执行系统粘贴后读取剪贴板文本与可选 HTML 列表结构；预览内容只保留在当前 Omi 进程内，不发送给豆包。
- API Key 仅保存在 macOS Keychain；Omi 不会在界面、命令行状态输出或诊断日志中回显它。
- 模型、Resource ID 与音色 ID 保存在本机 `UserDefaults`。

## 不会保存或收集的内容

- 不保存朗读文本、音频文件或朗读历史。
- 不提供账号体系、分析埋点或遥测上传。
- 不上传剪贴板原始 HTML、图片或其他非文本内容，也不读取完整聊天记录或屏幕内容。

## 本机日志

诊断日志只记录事件、剪贴板类型、原始/发送字符数、移除表格块数、分段数，以及经过脱敏的错误类别、HTTP 状态码、服务码和请求 ID。日志不记录 API Key、请求 Header、请求文本、剪贴板 HTML 或服务端原始响应体。

## 第三方服务与费用

过滤后的可朗读文本会被发送给豆包 TTS。豆包对该文本的处理、保留与费用适用其自身条款和隐私政策。你需要自行开通服务、配置配额并承担相关费用。

## 你的选择

请只朗读你有权发送给第三方云服务处理的文本。如果不希望文本离开设备，请不要触发云端朗读。
